## 🗄️ Database Structure

```
MongoDB: smart_campus
├─ users
│  ├─ name
│  ├─ email (unique)
│  ├─ password (hashed)
│  ├─ role (student/faculty/admin)
│  └─ created_at
│
├─ events
│  ├─ title
│  ├─ description
│  ├─ event_date
│  ├─ location
│  ├─ created_by → users
│  ├─ registered_users → [users]
│  └─ created_at
│
├─ lost_found
│  ├─ item_name
│  ├─ description
│  ├─ category (lost/found)
│  ├─ location
│  ├─ date
│  ├─ status (pending/claimed)
│  ├─ user_id → users
│  └─ created_at
│
├─ feedback
│  ├─ category
│  ├─ description
│  ├─ priority (high/medium/low)
│  ├─ status (pending/in_progress/resolved)
│  ├─ response
│  ├─ user_id → users
│  └─ created_at
│
├─ clubs
│  ├─ name
│  ├─ description
│  ├─ category
│  ├─ members → [users]
│  └─ created_at
│
└─ announcements
   ├─ title
   ├─ content
   ├─ priority (high/medium/low)
   └─ created_at
```
